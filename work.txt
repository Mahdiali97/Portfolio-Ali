## Overview

A high-concurrency web allocation and residential governance portal engineered for Kolej Harun Aminurrashid (KHAR). Built to eliminate physical queues and uncoordinated spreadsheet records, the platform provides automated, real-time dormitory room selection for thousands of university students during high-traffic intake windows.

## Core Architecture & Features

- **Multi-Student Group Booking**: Synchronized application system allowing peer groups of 2 to 4 students to link records and register for adjacent dorm rooms simultaneously.
- **Real-Time Allocation Engine**: Concurrency-safe room reservation pipeline with Livewire preventing double-booking race conditions during peak server loads.
- **Administrative Control Hub**: Interactive dashboard for residential staff to monitor block capacity, filter student eligibility, and approve housing claims.

## Technical Stack & Tools

- **Full-Stack Framework**: Laravel, Livewire
- **Styling & UI**: Tailwind CSS, Flux UI Components
- **Access Control**: Spatie Laravel-Permission
- **Database**: MySQL, SQLite
- **DevOps & Cloud**: Docker, Fly.io Deployment Pipeline
